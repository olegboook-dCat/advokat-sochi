# Сайт адвоката + модерация отзывов

Статический сайт-визитка с формой отзывов и **панелью модерации**.
Посетитель оставляет отзыв → он попадает «на модерацию» → администратор
(адвокат) в панели `/admin` нажимает **«Одобрить»**, и отзыв сразу
появляется на сайте. Публикуется только одобренное.

- Локально работает на **SQLite** — база не нужна, только PHP.
- На хостинге **Timeweb** — на **MySQL** (переключается в `config.php`).

---

## 1. Запуск локально (macOS)

### Шаг 1. Установить PHP (если ещё нет)
В свежих macOS PHP убрали, поставьте через [Homebrew](https://brew.sh):
```bash
brew install php
```
Проверка: `php -v` (нужна версия 8.x).

### Шаг 2. Запустить сайт
В терминале зайдите в папку проекта и запустите встроенный сервер:
```bash
cd путь/до/папки/проекта
php -S localhost:8000
```

### Шаг 3. Открыть в браузере
- Сайт: **http://localhost:8000**
- Панель модерации: **http://localhost:8000/admin**

### Данные для входа в панель (по умолчанию)
- Логин: `admin`
- Пароль: `changeme`

> ⚠️ **Обязательно смените пароль** перед публикацией (см. раздел 3).

База SQLite создастся автоматически в `data/reviews.sqlite`.
Чтобы очистить все отзывы локально — просто удалите этот файл.

## 2. Выкладка на Timeweb (MySQL)

### Шаг 1. Создать базу MySQL
В панели Timeweb создайте базу данных MySQL и запишите: **хост, имя базы,
пользователь, пароль**.

### Шаг 2. Создать таблицу
В phpMyAdmin вашей базы выполните SQL из файла [`schema.sql`](schema.sql).
(Если не сделать вручную — таблица всё равно создастся сама при первом
открытии сайта.)

### Шаг 3. Настроить `config.php`
Откройте `config.php` и задайте:
```php
define('DB_DRIVER', 'mysql');          // переключаем на MySQL
define('MYSQL_HOST', 'localhost');     // хост из панели Timeweb
define('MYSQL_NAME', 'имя_базы');      // из панели
define('MYSQL_USER', 'пользователь');  // из панели
define('MYSQL_PASS', 'пароль');        // из панели
```
Там же смените пароль администратора и секрет (раздел 3).

### Шаг 4. Загрузить файлы на хостинг
Любым удобным способом:
- **Git**: в панели Timeweb подключить репозиторий, либо по SSH `git clone`.
- **FTP/SFTP**: загрузить все файлы в корневую папку сайта.

### Шаг 5. Проверить
- Сайт: `https://ваш-домен/`
- Панель: `https://ваш-домен/admin`

Убедитесь, что включён **HTTPS** (для безопасного входа в панель).

## 3. Смена пароля администратора

1. Сгенерируйте хэш нового пароля:
   ```bash
   php -r "echo password_hash('ВАШ_НОВЫЙ_ПАРОЛЬ', PASSWORD_DEFAULT), PHP_EOL;"
   ```
2. Вставьте результат в `config.php`:
   ```php
   define('ADMIN_PASS_HASH', '$2y$12$...ваш-хэш...');
   ```
3. При желании смените логин `ADMIN_LOGIN` и обязательно —
   `APP_SECRET` (любая длинная случайная строка).

## 4. Что где лежит

| Файл / папка          | Назначение                                            |
|-----------------------|-------------------------------------------------------|
| `index.php`           | Главная страница сайта (отзывы берутся из базы)        |
| `styles.css`, `script.js` | Оформление и скрипты сайта                         |
| `assets/`             | Изображения (фон Hero, эмблема, фото)                  |
| `review-submit.php`   | Приём отзыва из формы (с проверками и анти-спамом)     |
| `admin/index.php`     | Панель модерации (вход + одобрить/скрыть/удалить)      |
| `admin/admin.css`     | Оформление панели                                     |
| `includes/db.php`     | Подключение к базе, автосоздание таблицы               |
| `includes/helpers.php`| Общие функции (безопасность, работа с отзывами)       |
| `config.php`          | Настройки: база, логин/пароль администратора           |
| `schema.sql`          | SQL для создания таблицы на MySQL (Timeweb)            |
| `data/`               | Локальная база SQLite (в репозиторий не попадает)      |

---

## 5. Безопасность (кратко)

- Отзывы сохраняются через подготовленные SQL-запросы (защита от инъекций).
- Пароль администратора хранится только в виде хэша.
- Форма защищена «ловушкой» для ботов и ограничением частоты отправки.
- Перед публикацией: смените пароль и `APP_SECRET`, включите HTTPS.
